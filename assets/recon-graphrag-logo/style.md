# Signal Graph — recon-graphrag visual identity

Style name: Signal Graph
Keywords: reconnaissance, network, precision, signal
Style description: A precise developer-tool identity built around a graph-shaped R monogram. Restrained scanning arcs communicate discovery and reconnaissance. Luminous nodes and deep spatial layers suggest connected knowledge without generic AI imagery.
Font plan: Space Grotesk for the distinctive geometric wordmark; IBM Plex Mono for technical labels and search-mode chips.
Color scheme: True black #050505 and near-black #0B0B0B; signal yellow #FFD60A; pure white #FFFFFF; neutral gray #A3A3A3. No chromatic accents beyond yellow.
Layout plan: The square logo centers the R network above a compact lowercase wordmark. The repository banner places the symbol at left and a right-aligned reading column at right. Use generous negative space and three meaningful feature chips.
Core visual requirements: Keep the R recognizable at small sizes. Place primary nodes on actual graph junctions. Keep scanning arcs secondary. Keep all artwork as editable vector geometry. Do not use stock graphics or generic robot/brain imagery.
